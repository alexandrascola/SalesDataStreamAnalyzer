# Sales Data Stream Analyzer

## Project Description
This program is written for a Java course and analyzes sales data from a CSV file using Java Streams.

## How to Run
1. Open the project in IntelliJ.
2. Open `src/Main.java`.
3. Run `Main.java`.
4. View the sales analysis results in the console.

## CSV File
The program analyzes data from `sales.csv`.
